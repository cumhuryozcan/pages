Support

Set, start, that's it. Set a duration, start the countdown, and hear a tone when time is up.

Getting started

Choose a duration with the duration picker or one of the built-in preset buttons, then start the countdown.

Durations can use seconds, minutes, and hours. The maximum duration is 99 hours, 59 minutes, and 59 seconds.

Timer controls

There is one active timer. While it is running, you can pause, resume, or reset it.

When time is up

When the countdown reaches zero, Timer One plays a sound and sends a notification. Sound is fixed and cannot be silenced.

Notifications are optional. If notification access is denied, the timer still runs but no notification is delivered.

Using Timer One

The timer continues running in the background, on the Lock Screen, and after switching apps.

The app works fully offline, without an account or external service.

Compatibility

Timer One supports iPhone running iOS 15 or later.

Timer One supports multiple languages.

Availability

Timer One is free and has no purchases.
